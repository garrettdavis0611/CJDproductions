# Evergreen & Brass Walk-In — build set

`closet-planner.html` is the drawing set for the 78" × 93" shared walk-in:
a scaled floor plan (A-1), both long-wall elevations (A-2, A-3), the back-wall
tower (A-4), the IKEA + non-IKEA takeoff, the budget derivation, and the
pre-order checks.

The one interactive control switches bay R2 between the specified
single-hang-over-four-drawers and a double hang matching R1. It redraws the
R2 elevation and updates every dependent quantity — shelves, rails, drawers,
brass pulls, total hanging, rod-light count and hanger capacity.

All dimensions are AFF (above finished floor) and follow the corrected frame
figures: PAX frames are 92⅞" tall, two of them measure 78¾", the leftover
wall is 14¼", the tower gap is 32¼", and the fillers are 1⅜" a side.

The file is published as a Claude Artifact, so it is written as page content
only — `<title>`, `<style>`, markup — with no `<!doctype>`/`<html>`/`<body>`
wrapper. To open it locally, wrap it in a minimal HTML skeleton first.
